1. ARQUITECTURA DEL SISTEMA
--------------------------------------------------------------------------------
El sistema es un ecosistema de agentes autónomos orquestados mediante un Bot de 
Telegram (Python). Se compone de tres capas principales:

A. CAPA DE INTERFAZ (bot.py):
   - Gestiona la comunicación con el usuario vía Telegram.
   - Utiliza 'python-telegram-bot' para manejar comandos, fotos y videos.
   - Implementa un sistema de botones interactivos para seleccionar escenarios.

B. CAPA DE INTELIGENCIA (agents.py):
   - Utiliza modelos locales (Qwen vía Ollama) o prompts estructurados para
     refinar los prompts de imagen/video.
   - Orquestador: Define qué herramienta (Grok, NanoBanana, Kling) usar según
     el requerimiento.

C. CAPA DE AUTOMATIZACIÓN (automation.py):
   - Motor: Playwright (Chromium).
   - Función: Navega físicamente por la web de ComfyUI Cloud para ejecutar flujos.
   - Navegación Agéntica: No depende de selectores estáticos simples; busca por 
     texto y contexto (Vídeo -> Grok -> Imagen a Video).

2. COMPONENTES Y ARCHIVOS CLAVE
--------------------------------------------------------------------------------
- /agent_bot/
  ├── bot.py           -> Entry point, lógica de Telegram y polling.
  ├── automation.py    -> Cerebro de navegación y gestión de descargas.
  ├── agents.py        -> Definición de roles y prompts del orquestador.
  ├── config.py        -> Tokens (Telegram), rutas (Chrome) y constantes.
  ├── accounts.json    -> Credenciales cifradas de ComfyUI (Cecilia Morales).
  ├── secret.key       -> Llave Fernet para el cifrado de accounts.json.
  ├── bot_log.txt      -> Registro de actividad del bot.
  └── start_agency.bat -> Script de arranque rápido.

3. FLUJO FUNCIONAL DE PRODUCCIÓN (CONVERSACIONAL)
--------------------------------------------------------------------------------
El bot ahora opera mediante una máquina de estados guiada:

1. CONFIGURACIÓN INICIAL:
   - Al iniciar con /start, el bot pide credenciales: `correo@gmail.com : contraseña`.
   - SEGURIDAD: Al registrar una cuenta nueva, las anteriores se eliminan automáticamente.

2. SELECCIÓN DE TAREA (/producir):
   - El bot pregunta mediante botones:
     A. Variaciones de Imagen (NanoBanana).
     B. Generar Video (Grok Imagen a Video).
     C. Replicar Video (Kling Motion Control).

3. REQUERIMIENTO DE MEDIOS:
   - Según la tarea, el bot solicita:
     • Imagen de referencia (para todas las tareas).
     • Video de muestra (solo para Kling Motion Control).

4. EJECUCIÓN AGÉNTICA:
   - El agente inicia sesión estrictamente vía Google Auth.
   - VERIFICACIÓN: El agente lee el balance de créditos. Si es <= 0, aborta y avisa.
   - NAVEGACIÓN: Localiza el workflow, sube los archivos y ejecuta el batch.

5. ENTREGA DE RESULTADOS:
   - El agente monitorea la descarga, la mueve a la carpeta final y la envía
     directamente al chat de Telegram.

MANUAL DE USUARIO (OPERACIÓN PASO A PASO)

PASO 1: Iniciar el bot.
